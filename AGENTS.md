# Правила проекта для AI-агентов (Codex, Claude, Gemini, Antigravity)

Этот файл читают все агенты, работающие в репозитории. Соблюдай его всегда.

## Проект
- AI-агент на харнесе: `harness/` (ядро и инструменты в `harness/tools/`), `api/`, `ui/`, `case/`.
- Описание харнеса и как добавлять инструменты — `HARNESS.md`.
- Кейс хакатона — `case/case.md`. Данные — `workspace/`.
- `README.md` — файл организаторов, не перезаписывай его.

## Правила
- Работай только в текущей ветке. Никогда не коммить в `main` напрямую, не делай force push.
- Не трогай файлы других участников без явной просьбы. Зоны — в `docs/team.md`.
- `.env` не читай, не выводи в ответ и не коммить. Ключи — только в `.env`.
- Новый инструмент агента = новый файл в `harness/tools/` по образцу `_template.py`.
  Ядро харнеса (`harness/agent.py`, `router.py`, `context.py`, `memory.py`, `rag.py`) меняй только при необходимости.
- После изменений запускай `python tests/smoke_test.py`. Если менялся UI — проверь, что
  `streamlit run ui/app.py` стартует без ошибок.
- Приоритет — стабильное живое демо. Лучше меньше функций, но без сбоев.
- Сообщения коммитов — коротко на английском.
